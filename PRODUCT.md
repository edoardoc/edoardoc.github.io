## Platform

web

## Product Purpose

500nits is Eddy's independent software label. The hub introduces the label, links to its live products, and invites visitors to subscribe to product updates.

Position the label around software broadly rather than particular devices or operating systems. Eddy suggested AI-era framing and expects to add a video game. Do not imply that every project uses AI, list an unreleased game as available, or invent a release date.

## Users

Visitors exploring Eddy's software and people who want to hear about releases. Inferred from the redesign request and existing product links; a more specific audience is undecided.

## Capabilities and Constraints

Static HTML and CSS, with minimal progressive JavaScript where useful. Preserve ordinary HTML navigation, canonical URLs, product facts, accessibility, and the existing repository release process. The hub's About page at https://500nits.com/about/ introduces Eddy's software work. Eddy's personal writing site is not ready to link from the hub.

The email newsletter provider and account are undecided. Never invent a working subscription endpoint or show an unearned success state.

## Brand Commitments

Always write 500nits in lowercase. Eddy speaks in first person singular. The user requested a simple, lo-fi, restrained one-person-company website based on favicon.svg and its two-color appearance. The asset itself specifies navy #1f2d4d with a transparent background; white is the inferred second color.

## Evidence on Hand

index.html contains product facts for Doodle Tag and Task for Spaces, a Botify project link, Eddy's contact address, and company registration details. favicon.svg contains the existing mark. .agents/SITES.md defines the canonical site inventory. Do not invent release dates, prices, ratings, testimonials, or account connections.

## Product Principles

- Make the person and the products easy to understand.
- Put the invitation to subscribe where visitors can find it immediately.
- Keep the site lightweight enough for one developer to maintain.
- Preserve clear links to each product and to the hub's About page. Do not link to Eddy's unfinished personal site.
